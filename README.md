# evolution-chart2 (WeWeb Element)

Custom WeWeb component of type **element**, built with Vue 3 (provided by WeWeb).

## Requirements

- Node.js >= 18

## Development

```bash
# Install dependencies
npm install

# Start dev server (default port 8080, served over HTTPS)
npm run serve

# Optional: use another port
npm run serve -- port=4040
```

Then open `https://localhost:8080` (or your chosen port) and authorize the invalid certificate if prompted.

## Build

```bash
npm run build
```
